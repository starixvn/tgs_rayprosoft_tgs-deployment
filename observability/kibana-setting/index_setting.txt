# https://www.elastic.co/guide/en/elasticsearch/reference/current/indices-rollover-index.html#roll-over-index-alias-with-write-index
# 執行之前要先把jaeger-collector跟jaeger-query 停掉


## dev 

### Sample
    <jaeger-span-{now/d}-000001> 
PUT %3Cjaeger-span-%7Bnow%2Fd%7D-000001%3E
{
  "aliases": {
    "jaeger-span-write": {
      "is_write_index": true
    }
  }
}

PUT %3Cjaeger-service-%7Bnow%2Fd%7D-000001%3E
{
  "aliases": {
    "jaeger-service-write": {
      "is_write_index": true
    }
  }
}
